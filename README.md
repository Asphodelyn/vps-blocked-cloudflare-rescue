## 按情况找

| 你现在的情况 | 去看 |
|---|---|
| 服务器 IP 被墙了，节点和网站全连不上 | 1-全流程，开头有"先看你是哪种情况"，按你服务器上有什么走对应的分支 |
| 节点能用，想配好不漏 IP、不漏 DNS | 2-客户端防泄露全套，从头看 |
| 节点连上了，但网站看到的还是国内 IP，或者 DNS 测出国内运营商 | 2-客户端防泄露全套，第 6 节验收 → 对照第 1 节找是哪里漏的 |
| Cloudflare 报 520～526 | 1-全流程，第 6 步，或者文末的"52x 报错速查" |
| 浏览器提示"重定向次数过多" | 1-全流程，第 6 步 |
| 节点在某个运营商下连不上、测速一直 -1 | 1-全流程，第 8 步 |
| 服务器访问谷歌提示"地区不支持"，或者访问国内网站超时 | 3-其他踩坑，第 1 节 |
| 443 被 Reality 节点占着，还想在上面跑网站 | 3-其他踩坑，第 2 节 |
| SSH 连不上自己的服务器 | 3-其他踩坑，第 3 节 |
| 开了防火墙之后服务挂了，或者把自己锁在了外面 | 3-其他踩坑，第 4 节 |

## 三份分别讲什么

- 1-IP被墙后买域名接Cloudflare全流程：从买域名、接 Cloudflare、配证书，到把网站和节点都接回来。分成"只有节点 / 只有网站 / 两样都有"三条路。
- 2-客户端防泄露全套：Windows 上的 v2rayN 和安卓上的 v2rayNG 怎么配，才能让 IP、DNS、IPv6、WebRTC 都不漏，最后怎么验收。
- 3-其他踩坑：服务器出站被拒（WARP）、443 共用、SSH、防火墙这些零散的坑。
